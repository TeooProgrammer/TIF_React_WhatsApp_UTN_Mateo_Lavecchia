# TIF React UTN - Connect, app inspirada en WhatsApp Web, Mateo Lavecchia
Aplicación de mensajería inspirada en la práctica de WhatsApp. El proyecto permite visualizar conversaciones, enviar mensajes, buscar contactos, agregar contactos nuevos e iniciar chats.

 ## Requisitos de la consigna incluidos 
 - Aplicación desarrollada en React. 
 - Componentes reutilizables.
 - Estados con useState.
 - Contexto global con Context API.
 - Enrutamiento con react-router-dom.
 - Mas de dos paginas: chats, conversación, contactos y acerca del proyecto.
 - Parametro dinamico en /chat/:chatId.
 - Parametro de busqueda en /contactos?q=texto mediante useSearchParams.
 - Formularios para enviar mensajes y agregar contactos.
 - Diseño responsive desde 320px hasta 2000px. 
 - Estilos con contraste legible, etiquetas asociadas a inputs y foco visible. 
 - Codigo organizado siguiendo DRY, KISS y YAGNI. 
 - Configuracion para desplegar una SPA en Vercel.

  ## Librerías utilizadas 
  - React 
  - React DOM 
  - React Router DOM 
  - Vite No se utilizaron librerías visuales externas. Los estilos están realizados con CSS.

## Dificultades presentadas 
Las dificultades que tuve fueron mas que nada al compartir información entre las páginas, conservar una estructura simple y responsive. Se resolvieron utilizando Context API, componentes pequeños, rutas claras y media queries.
